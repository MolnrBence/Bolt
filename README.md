A projekt működéséhez be kell idítani a xamppot ez lehetővé teszi, hogy a backend-ben lefuttassuk futtatni a php artisan migrate -seed paracsot ez feltölti az adatbázist a backend beüzemelése utolsó lépéseként le kell futattni a php artisan serve parancsot ezután a backend probléma nélül működni fog.
Ha a backendet beüzemeltük és be van idulva akkor kell megnyitni a frontendet. A frontendben egy fontos parancsot kell lefutattni a működéséhez. Ez a parancs a npm install @angular/build@21 --save-dev parancs, ez teszi lehetővé hogy futtatni lehessen a frontendet e nélkül nem fog elindulni. Ha az előbb említett parancsot viszont lefuttatjuk akkor ez lehetővé teszi, hogy elindítsuk a frondend-et is a következő két parancs eggyikével. Vagy a ng serve vagy az ng serve -o segítségével. A két parancs között annyi a különbség, hogy amíg az ng serve az csak elindítja a frontendet az ng serve -o meg is nyitja azt.
